# Markdown 방언 명세 (0.1, 초안)

`@9um4/editor-markdown`이 쓰고 읽는 Markdown의 규칙이다. 에디터 패키지 설계는 [EDITOR-PACKAGE.md](EDITOR-PACKAGE.md) §6과 P3.
**이 문서의 모든 규칙은 `packages/editor-markdown/fixtures/`의 골든으로 고정돼 있다**(문서 → Markdown, Markdown → 문서, 왕복). 규칙을 바꾸면 골든을 갱신하고 이 문서도 고친다.

## 원칙

1. **Obsidian 호환 Markdown의 상위 집합**이다. 기반은 CommonMark + GFM(표, 취소선, 할 일).
2. **쓰기는 보수적, 읽기는 관대하게.** 우리가 쓰는 문법은 아래 표의 것뿐이고, 읽을 때는 Obsidian 별칭·HTML 일부까지 받는다.
3. **내용을 버리지 않는다.** 읽지 못하는 것은 글자로 남기고 `notices`(안내 문구)로 알린다.
4. 원본은 Yjs/JSON이다. Markdown은 파생물이라 **잃는 것이 있다** — 아래 "알려진 손실" 목록이 전부다.
5. Notion은 **가져오기만** 한다(미검증 — 아래 "검증 상태").

| 동기화 블록 | 내용을 그 자리에 복사 | — | 동기화 관계는 사라짐 |

## 인라인

| 마크 | 쓰기 | 비고 |
|---|---|---|
| 굵게 / 기울임 / 취소선 | `**` / `*` / `~~` | |
| 인라인 코드 | `` ` `` (안에 백틱이 있으면 더 긴 표시) | |
| 링크 | `[글](주소)` | `http` `https` `mailto`만 열 수 있는 링크로 읽는다 |
| 밑줄 | `<u>…</u>` | Markdown에 없어서 HTML로 쓰고 안내한다 |
| 페이지 링크 | `[[제목]]` | 제목이 같은 페이지가 여럿이면 모호함(내보내기 계획이 파일 이름을 구분) |
| 인라인 수식 | `$…$` | 줄바꿈은 공백으로. 숫자만 든 `$5$`는 수식이 아니다 |
| 각주 | `[^1]` + 문서 끝 `[^1]: 내용` | 번호는 문서 순서 |

글자 속의 `\ ` `` ` `` `*` `_` `[` `]` `<` `~`는 `\`로 이스케이프하고, 줄 맨 앞의 `#` `-` `+` `>` 와 `1.` 도 이스케이프한다.

## 목록 경계

같은 계열의 목록이 바로 이어지면(글머리·할 일, 또는 번호) Markdown은 한 목록으로 합친다. 그래서 **둘째부터는 기호를 바꿔 쓴다**: 글머리·할 일은 `-` ↔ `*`, 번호는 `.` ↔ `)`.

## 블록 id (`^id`)

내보내기 옵션 `blockIds`가 켜지면(전체 내보내기는 켠다, 한 페이지 복사·내보내기는 끈다) Obsidian의 블록 id를 쓴다.

| 블록 | 쓰기 |
|---|---|
| 문단·제목 | 마지막 줄 끝에 ` ^id` (목록 항목·인용·콜아웃 안의 문단도 같다) |
| 코드·수식·표·이미지 | 블록 아래 **빈 줄 뒤 한 줄**에 `^id` |
| 목록·인용·콜아웃·토글·구분선·페이지 블록 | 쓰지 않는다 — 블록 링크는 글이 있는 블록(위 두 줄)만 가리킬 수 있고, 안의 문단이 자기 id를 가진다. 가져오면 새 id가 생긴다 |
| 블록 링크 | `[[이름#^id]]` (`blockIds`가 꺼지면 페이지 링크 `[[이름]]`로 바뀐다) |

읽기: 줄 끝의 ` ^id`(3글자 이상, 글자 포함 — `x ^2` 같은 지수 표기는 id가 아니다)와 홀로 있는 `^id` 줄(바로 앞 블록의 id)을 읽는다. `[[이름#^id]]`는 블록 링크로 읽고 `[[이름#제목]]`은 위치를 버리고 안내한다. 코드 안의 `^id`는 그대로 둔다.

**id 모양**: 이 앱의 id(소문자·숫자 10글자)는 그대로 쓴다. 다른 모양(Obsidian 사용자가 만든 `^my-quote`)은 글자에서 **정해지는** id로 바꾼다(`blockIdFromForeign`: FNV-1a 64비트 → 36진수 10글자). 블록과 링크를 따로 가져와도 같은 id가 되어 이어진다. 이 값은 고정이다 — 바뀌면 이미 가져온 노트의 블록 링크가 끊어진다.

## 표

GFM 표는 병합 셀, 머리글 없는 표, 셀 안의 여러 블록을 표현하지 못한다.

- 병합 셀은 풀어서 쓴다(남는 칸은 빈 칸). 안내한다.
- 첫 줄을 항상 머리글로 쓴다. 머리글 행이 없던 표는 안내한다.
- 셀 안 문단 여럿은 `<br>`로 이어 쓰고, 읽으면 한 문단 안의 줄바꿈이 된다.
- `|`는 `\|`로 쓴다.

2. **쓰기는 보수적, 읽기는 관대하게.** 우리가 쓰는 문법은 아래 표의 것뿐이고, 읽을 때는 Obsidian 별칭·HTML 일부까지 받는다.
3. **내용을 버리지 않는다.** 읽지 못하는 것은 글자로 남기고 `notices`(안내 문구)로 알린다.
4. 원본은 Yjs/JSON이다. Markdown은 파생물이라 **잃는 것이 있다** — 아래 "알려진 손실" 목록이 전부다.
5. Notion은 **가져오기만** 한다(미검증 — 아래 "검증 상태").

| 표 | GFM 표 | 같음 | 아래 "표" 참고 |

| 페이지 카드 | `[[제목]]` 한 줄 | — | 읽으면 문단 안의 페이지 링크가 됨 |
| 동기화 블록 | 내용을 그 자리에 복사 | — | 동기화 관계는 사라짐 |

## 인라인

| 마크 | 쓰기 | 비고 |
|---|---|---|
| 굵게 / 기울임 / 취소선 | `**` / `*` / `~~` | |
| 인라인 코드 | `` ` `` (안에 백틱이 있으면 더 긴 표시) | |
| 링크 | `[글](주소)` | `http` `https` `mailto`만 열 수 있는 링크로 읽는다 |
| 밑줄 | `<u>…</u>` | Markdown에 없어서 HTML로 쓰고 안내한다 |
| 페이지 링크 | `[[제목]]` | 제목이 같은 페이지가 여럿이면 모호함(내보내기 계획이 파일 이름을 구분) |
| 인라인 수식 | `$…$` | 줄바꿈은 공백으로. 숫자만 든 `$5$`는 수식이 아니다 |
| 각주 | `[^1]` + 문서 끝 `[^1]: 내용` | 번호는 문서 순서 |

글자 속의 `\ ` `` ` `` `*` `_` `[` `]` `<` `~`는 `\`로 이스케이프하고, 줄 맨 앞의 `#` `-` `+` `>` 와 `1.` 도 이스케이프한다.

## 목록 경계

같은 계열의 목록이 바로 이어지면(글머리·할 일, 또는 번호) Markdown은 한 목록으로 합친다. 그래서 **둘째부터는 기호를 바꿔 쓴다**: 글머리·할 일은 `-` ↔ `*`, 번호는 `.` ↔ `)`.

## 블록 id (`^id`)

내보내기 옵션 `blockIds`가 켜지면(전체 내보내기는 켠다, 한 페이지 복사·내보내기는 끈다) Obsidian의 블록 id를 쓴다.

| 블록 | 쓰기 |
|---|---|
| 문단·제목 | 마지막 줄 끝에 ` ^id` (목록 항목·인용·콜아웃 안의 문단도 같다) |
| 코드·수식·표·이미지 | 블록 아래 **빈 줄 뒤 한 줄**에 `^id` |
| 목록·인용·콜아웃·토글·구분선·페이지 블록 | 쓰지 않는다 — 블록 링크는 글이 있는 블록(위 두 줄)만 가리킬 수 있고, 안의 문단이 자기 id를 가진다. 가져오면 새 id가 생긴다 |
| 블록 링크 | `[[이름#^id]]` (`blockIds`가 꺼지면 페이지 링크 `[[이름]]`로 바뀐다) |

읽기: 줄 끝의 ` ^id`(3글자 이상, 글자 포함 — `x ^2` 같은 지수 표기는 id가 아니다)와 홀로 있는 `^id` 줄(바로 앞 블록의 id)을 읽는다. `[[이름#^id]]`는 블록 링크로 읽고 `[[이름#제목]]`은 위치를 버리고 안내한다. 코드 안의 `^id`는 그대로 둔다.

**id 모양**: 이 앱의 id(소문자·숫자 10글자)는 그대로 쓴다. 다른 모양(Obsidian 사용자가 만든 `^my-quote`)은 글자에서 **정해지는** id로 바꾼다(`blockIdFromForeign`: FNV-1a 64비트 → 36진수 10글자). 블록과 링크를 따로 가져와도 같은 id가 되어 이어진다. 이 값은 고정이다 — 바뀌면 이미 가져온 노트의 블록 링크가 끊어진다.

## 표

GFM 표는 병합 셀, 머리글 없는 표, 셀 안의 여러 블록을 표현하지 못한다.

- 병합 셀은 풀어서 쓴다(남는 칸은 빈 칸). 안내한다.
- 첫 줄을 항상 머리글로 쓴다. 머리글 행이 없던 표는 안내한다.
- 셀 안 문단 여럿은 `<br>`로 이어 쓰고, 읽으면 한 문단 안의 줄바꿈이 된다.
- `|`는 `\|`로 쓴다.

- 이미지는 붙여넣기에서 가져오지 않는다(경로를 해석할 폴더가 없다) — 글자로 남는다.

## 복사 시 Markdown (옵션)

`createCoreExtensions({ copyAsMarkdown })`가 켜지면 복사할 때 `text/plain`이 Markdown이 된다(`MarkdownCopy.ts`). `text/html`은 그대로라서 에디터끼리의 복사와 웹 페이지 붙여넣기는 변하지 않는다. 글자 일부만 고른 복사도 서식(`**굵게**`)이 유지되고, 코드 블록 안의 글은 이스케이프 없이 코드 그대로다.
**기본은 꺼짐이고 노트 앱도 끈다** — 메모장 같은 곳에 붙이면 `**` 같은 기호가 보이기 때문이다. Obsidian으로 옮기는 용도라면 블로그·캘린더 같은 소비자가 켠다.

## frontmatter

가져오기에서만 해석한다(`---` 사이의 YAML 부분 집합: 문자열, 한 줄 목록, `- ` 목록). 내보내기가 쓰는 속성은 앱(전체 내보내기)이 정한다.

## 알려진 손실 (0.1)

내보냈다가 다시 읽으면 다음이 달라진다. 골든의 `lossless: false` 픽스처와 `*.imported.json`이 실제 모양을 보여 준다.

1. **블록 id**: 한 페이지 내보내기(`blockIds` 끔)에서는 사라지고 블록 링크는 페이지 링크가 된다. 전체 내보내기에서도 목록·인용·콜아웃·토글·구분선·페이지 블록의 id는 남지 않는다(글이 있는 블록의 id와 블록 링크는 남는다).
2. **페이지 카드**는 링크 한 줄이 되고, 읽으면 문단 속 페이지 링크가 된다.
3. **동기화 블록**은 그 자리에 복사되고 동기화 관계는 사라진다.
4. **표**: 병합 셀 풀림, 머리글 없는 표는 첫 줄이 머리글, 셀 안 문단 여럿은 한 문단.
5. **정렬**: 목록·표 안의 정렬은 쓰지 않는다. 왼쪽 정렬은 속성이 없는 것과 같다.
6. **빈 문단**은 사라진다.
7. **이미지**는 파일 경로가 되고 해시가 다시 계산된다. 크기는 Obsidian 형식이라 다른 편집기에서는 적용되지 않을 수 있다.
8. **콜아웃**의 접힘 표시와 Obsidian 별칭 이름은 읽을 때 다섯 종류로 줄어든다.
9. **모르는 HTML**은 태그를 빼고 글자만 가져온다.
10. 안내 문구(`notices`)는 지금 한국어로만 나온다.

## 검증 상태

- 골든 픽스처 14개: 우리가 쓴 것을 우리가 읽는 왕복. 자동 시험.
- **Obsidian·Notion 실제 파일로는 검증하지 않았다.** 위 표의 Obsidian 호환은 공개 문서에 적힌 문법을 근거로 한 것이다. 샘플이 오면 `fixtures/`에 추가한다(P3-6).
